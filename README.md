# Vulkan Tutorial 中文镜像

这是 Khronos Vulkan Tutorial 的非官方中文镜像，跟随官方教程更新，供中文阅读和中英对照学习。基础译文来自 Google 翻译，部分段落经 Copilot 对照英文做了小幅校订。涉及 API 行为和技术约束时，请以官方英文原文为准。[官方教程](https://docs.vulkan.org/tutorial/)

**[在线阅读 Vulkan 教程](https://seu-yx.github.io/vulkan-tutorial-zh/)**

- 支持中文、英文和逐段中英对照，可悬浮查看术语原文，也可直接显示英文术语。
- 多级章节目录支持搜索、展开和定位，桌面端可调整侧栏宽度。
- 保留源代码和 Vulkan API 名称，提供 GitHub 风格高亮、代码复制和深浅色主题。
- 每章附官方原文、对应版本的源码和许可说明。
